One line a smart fridge texts its owner at 3am: the fridge has watched one too
many midnight cake raids, so it turns snitch and tells the fitness app — then
reminds its owner what a fridge actually does. It keeps things. It does not
keep secrets.

## Run it

```sh
node main.ts
```

Writes the text to `/output/entry.txt` (111 characters, UTF-8).
